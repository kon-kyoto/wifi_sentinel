# 📡 Wi-Fi Sentinel – Твой цифровой детектор движения

> *"Тишина в эфире — это тоже сигнал. Но чаще там шумят."*

Представь: ты сидишь в кафе, попиваешь кофе, а вокруг тебя десятки устройств кричат в пустоту: «Где моя домашняя сеть? А Starbucks? А эта Wi-Fi точка, которую я запомнил три года назад?»

Wi‑Fi Sentinel слушает этот **тихий крик**.
Он не подключается, не светится, не шумит. Он просто **знает**, кто рядом.

---

## ✨ Что умеет этот зверь?

| Режим | Что видит | Зачем |
|-------|-----------|-------|
| **MAC detection** | Все устройства в радиусе | «А кто тут у нас ходит?» |
| **PROBE tracking** | Клиент → какая сеть нужна | «Ты ищешь Starbucks? Понял, запомнил.» |
| **HTTP sniffing** | Сайты, заголовки, POST‑данные | «О, кто-то заходит на ... (не суди, это для науки)» |
| **Channel hopping** | Прыгает по 13 каналам | «Ничего не пропущу, я вездесущ.» |

> *"Пассивный сканер не оставляет следов. Как призрак, который ведёт дневник."*

## 🚀 Запуск одной строкой

```bash
# Клонируй
git clone https://github.com/yourusername/wifi-sentinel.git
cd wifi-sentinel

# Подготовь среду
python3 -m venv venv
source venv/bin/activate
pip install scapy

# Вжух — и ты в матрице
sudo python sentinel.py wlan0 -w my_scan
```

Остановка — `Ctrl+C`. Всё сохранится в CSV.

## 🎮 Режимы на все случаи жизни

```bash
# Полный фарш (MAC + PROBE + HTTP)
sudo python sentinel.py wlan0 -w full_scan

# Только подглядываю за HTTP
sudo python sentinel.py wlan0 --http

# Кто к кому стучится (probe request/response)
sudo python sentinel.py wlan0 --prob

# Сижу на одном канале (как снайпер)
sudo python sentinel.py wlan0 -c 6

# Всё вместе и в файл
sudo python sentinel.py wlan0 --mac --prob --http -w everything
```

> *"Параметры как мантры. Выучишь — станешь джедаем сниффинга."*

## 📂 Что ты получишь на выходе

### `scan_mac.csv` — кто есть кто
| mac | essid | channel | is_ap |

| AA:BB:CC:DD:EE:FF | HomeNetwork | 6 | YES |
| 11:22:33:44:55:66 | Starbucks, Airport | 1 | NO |

| client_mac | target_mac | ssid | type |
|------------|------------|------|-------|
| AA:BB:CC:DD:EE:FF | FF:FF:FF:FF:FF:FF | HomeNetwork | request |
| 11:22:33:44:55:66 | 77:88:99:AA:BB:CC | CoffeeShop | response |

### `scan_http.csv` — что смотрят в интернете
| timestamp | src_ip | host | path | user_agent | post_data |
|-----------|--------|------|------|------------|-----------|
| 2025-01-15 14:23:05 | 192.168.1.100 | example.com | /login | Mozilla/5.0 | user=admin&pass=*** |

> *"CSV — это исповедь устройств. Только они не знают, что их читают."*

## 🧠 Как это работает (для тех, кто любит копать)

```
Твой Wi-Fi адаптер (в режиме монитора)
         ↓
   прыгает по каналам (1-13)
         ↓
   ловит всё подряд (scapy)
         ↓
   ┌─────────────┼─────────────┐
   ↓             ↓             ↓
  MAC          PROBE         HTTP
(beacon/    (request/     (request/
 probe req)   response)     response)
   ↓             ↓             ↓
  CSV          CSV           CSV
```

**Ты не подключаешься → тебя не видно.**  
**Ты слушаешь → ты знаешь.**

> *"Лучший способ остаться незамеченным — не светиться. Sentinel не светится."*

---

## 🛠️ Что тебе понадобится (железо)

- **Wi-Fi адаптер с поддержкой monitor mode**
  - Alfa AWUS036ACH (народная любовь)
  - Atheros AR9271 (старый, но надёжный)
  - Некоторые внутренние Intel карты (проверь `iw list | grep monitor`)

- **Linux** (Arch, Kali, Ubuntu, Raspberry Pi OS — любые)

> *"Windows не подойдёт. Серьёзно. Даже не пытайся."*

---

## 🧪 Где проверено

- ✅ Arch Linux + Alfa AWUS036ACH (ядро 6.12)
- ✅ Raspberry Pi 4 + встроенный Wi‑Fi
- ✅ Kali Linux (виртуалка — да, тоже работает)

## ⚠️ Юридическая мантра

- Этот инструмент — для **твоих собственных сетей** или с **письменного разрешения**.
- Пассивный сниффинг — это ещё не взлом, но законы бывают странными.
- Не будь тем парнем, который деаутет кофейню.

> *"С большой силой приходит большая ответственность. И немного паранойи."*
